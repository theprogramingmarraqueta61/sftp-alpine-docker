# SFTP Alpine Linux + Docker

## Descripción del proyecto

Este proyecto consiste en la implementación y documentación de un **servidor de transferencia de archivos mediante SFTP**, utilizando **Alpine Linux** como sistema operativo base y **Docker** como tecnología de contenedorización.

El objetivo del proyecto es disponer de un entorno SFTP aislado y reproducible mediante un contenedor Docker, permitiendo trabajar con un servicio de transferencia de archivos basado en SSH. El repositorio reúne la documentación y los archivos utilizados como respaldo del desarrollo y las pruebas realizadas durante el proyecto.

## Tecnologías principales

- **Alpine Linux**: distribución Linux utilizada como base del entorno del servidor.
- **Docker**: utilizado para contenerizar el servicio.
- **SFTP (SSH File Transfer Protocol)**: protocolo empleado para la transferencia segura de archivos.
- **SSH**: tecnología sobre la que se basa el servicio SFTP.
